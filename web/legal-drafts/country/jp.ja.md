# 日本

このセクションは英語と日本語で提供します。内容に相違がある場合は英語版が優先します。

このセクションは、日本にお住まいの方に適用されます。KIFF のプライバシーポリシーと tafs のプライバシーポリシーに加えて、個人情報の保護に関する法律（個人情報保護法）が求める事項を定めます。

## 1. 利用目的

お客様の個人情報は、アカウントの作成・維持とログイン、tafs に任せた業務の実行、有料プランの請求、サービスの安全確保のためにのみ利用します。これ以外の目的で利用する場合は、事前にお客様にお尋ねします。

## 2. 外国にある第三者への提供

お客様の個人情報は、日本国外の提供先に提供されます。国ごとの内容は次のとおりです。

| 国 | 提供先 | その国の個人情報保護制度 |
|---|---|---|
| アイルランド、EU | Kiff Agents OÜ（エストニア）、Amazon Web Services、Stripe | EU の一般データ保護規則（GDPR）。個人情報保護委員会は、EU を日本と同等の水準にある制度を有する地域として認めています。 |
| 米国 | Clerk、Anthropic、Stripe、Resend、Cloudflare、Google、Apple、Composio | 包括的な連邦法はなく、分野別の法律とカリフォルニア州の CCPA などの州法があります。連邦取引委員会（FTC）は不公正・欺瞞的な行為に対して措置をとることができます。 |
| Anthropic のモデルが実行されることがあるその他の国（欧州、アジア、オーストラリア） | Anthropic | その国の法律。どこで実行されても、下記「当社の措置」の書面の契約が適用されます。 |

**当社の措置.** 各提供先とは、個人情報保護法の基準に沿ってお客様の個人情報を取り扱うことを定めた書面の契約を結んでいます。定められた目的にのみ利用し、安全に管理し、同じ条件なしに他者へ提供せず、業務終了時には削除または返還します。当社はこれらの措置を定期的に確認しており、詳しい内容はお問い合わせいただければお知らせします。

## 3. 安全管理措置

データベースで顧客ごとのデータを分離し、通信時（TLS 1.2 以上）と保存時に暗号化し、アクセスを必要な者に限定し、操作を承認する鍵はお客様ご自身の端末に保管しています。漏えい等によりお客様の権利利益を害するおそれがある場合は、個人情報保護委員会に報告し、お客様にお知らせします。

## 4. 開示等の請求

保有個人データの開示、訂正・追加・削除、利用停止・消去、第三者提供の停止、外国にある第三者への提供の停止、第三者提供記録の開示を請求できます。privacy@kiff.dev までご連絡ください。遅滞なく対応し、手数料はいただきません。
