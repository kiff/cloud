# Try a version beside the live one

A changed taf is saved as a new **version** you can try before it replaces the live one.
For whoever changes a taf's job or Card.
The live version keeps working while you try; its schedule, Card and budget don't change.

## Try it

In **Versions**, choose **Try**, then **Start trying** with Face ID. You chat with it in a window
marked **not live**. Its calls are real, under a test Card that counts from zero, so that day the
taf can spend both Cards' limits.

## End it

**Install** makes it live, with its Card, with Face ID. **Go back** stops the test Card at once.
Either way the test chat is deleted. An unused test ends after 30 days.
